## How our repositories work

Every Foundation-0 repo follows the [Repository Standard](https://github.com/Foundation-0/.github/blob/main/REPO-STANDARD.md),
modelled on [incentre-lattices](https://github.com/Foundation-0/incentre-lattices):
an interactive page, a paper, and a machine that re-checks its own claims.
Claims are labelled **PROVEN**, **VERIFIED** (finite check), **KNOWN**
(cited), or **CONJECTURE** — and "not found" is never called "new".
